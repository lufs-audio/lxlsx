# Unit 06 — CLI + registry (bin, `run`, `list`, `index`)

## Objective
Implement the `lxlsx` binary (clap derive): `snapshot`, `run <slug>`, `list`, `verify`,
`index [--check]` — plus the filesystem-as-registry `processes/` with a generated
`index.json` and the first process manifest.

## Context
CLI name `lxlsx` (5 chars, compliant per `bplate/docs/units/07`). Exit codes and envelope
per `bplate/docs/units/10` and SPEC.md. Registry per `filesystem-as-registry`: folder-per-entry
`processes/<slug>/manifest.json` + generated `processes/index.json`; `index --check` fails
(exit 5) if the index is stale.

## Acceptance criteria
- [ ] `lxlsx snapshot --db <p> --out <x> [--json] [--last-met D]` renders; `--json` emits the envelope.
- [ ] `lxlsx run <slug>` dispatches to the registered process (initially `snapshot`); unknown slug → exit 4.
- [ ] `lxlsx list [--json]` enumerates registry entries.
- [ ] `lxlsx verify --xlsx <p>` run read-back verifier → exit 0/5.
- [ ] `lxlsx index` writes `processes/index.json`; `index --check` exits 5 on drift.
- [ ] `processes/snapshot/manifest.json` declares name, slug, description, function (read→render→verify), and its contract (the six blocks).
- [ ] Every flag/exit path documented in `--help`.

## Interface contract
The registry manifest schema: `{"slug","name","description","stages":["read","render","verify"],"contract":{…}}`. `index.json` is `{"processes":[<manifest reference>…]}` generated by walking `processes/*/manifest.json`.

## Boundaries — do NOT touch
Kernel `src/` (Units 01–04). Do not invent a config format beyond the manifest + args.

## Output
`src/main.rs`, `processes/snapshot/manifest.json`, an index generator (`src/registry.rs` or a `bin/lxlsx-index.rs` path), `AGENTS.md`, `README.md`, `CHANGELOG.md`.

## Verification
`cargo test` + a CLI integration test asserting `lxlsx list --json` and `lxlsx index --check` behavior.
